# Wood Mallet — turned-handle shop mallet (CAD)

> *A wooden shop mallet for chisel and joinery work — a turned handle seated into a solid head. SolidWorks model recovered from my 2018 archive.*

## What this is

A traditional wooden mallet of the kind I reach for at the bench: a chunky head you strike with, and a turned handle wedged into it. This is the persuader for driving bench chisels, seating joints, and any tap-it-home work where a steel hammer would bruise the wood or mushroom a chisel handle. The handle is turned on the lathe (there's both a pre-turn blank part and the turned profile in the set), and the head is a single block bored to take it.

This folder holds the SolidWorks CAD only — the design as modeled, not a build log. I'm recovering it here so the geometry doesn't get lost.

## Files

Inventoried from this folder:

- `Mallet.SLDASM` — top-level assembly (head + turned handle)
- `Mallet Head.SLDPRT` — the striking head
- `Mallet Handle.SLDPRT` — the handle (pre-turn / square-ish stock part)
- `Mallet Handle Turned.SLDPRT` — the handle turned to its finished round profile
